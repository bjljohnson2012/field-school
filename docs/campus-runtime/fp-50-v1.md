## Score

Sum (answer - 3) times weight per dimension. Store raw sums. Map to 0-100. Softmax correspondence matrices live in code next to this version. Do not claim official types. Child run uses the 20 child=y rows only.

## Profile

`member_profiles` on the person: bearing, correspondences, narrative (how_you_learn, how_you_approach, how_you_handle_conflict, how_you_take_feedback, how_you_show_up_in_a_group, working_title), evidence_summary.

`member_profile_revisions` append-only.

Skills stay on the membership (`skill_states`).

Narrative v1 is template-from-threshold. Pace high: short sessions. Abstraction low: example first. Challenge low + Harmony high: private written feedback. Expression high: talk-back or short Loom. A model may polish. It may not invent a type the scores do not support.

## Continuous update

Pattern run resets Bearing. Artifacts (paper, STT from voice/video) nudge with step 0.15. Quiz step 0.05. Clamp 0-100. Rewrite a narrative paragraph only if its keys moved 8+ points. Parent may set profile.locked. Household Pattern never appears on the sales board.
